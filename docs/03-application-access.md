# 03 — Application Access

## Goal
Practice the distinction between an application registration and an enterprise application/service principal, then control access to a test application.

## Lab outcome

Document:

- Application identity
- Who can sign in
- Which users/groups are assigned
- What access is granted
- How access can be removed

## Evidence checklist

- [ ] Test application identified
- [ ] Enterprise application reviewed
- [ ] Group/user assignment configured
- [ ] Access path documented
