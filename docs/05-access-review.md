# 05 — Access Review

## Goal
Demonstrate periodic recertification of access to a group or application.

## Scenario

The `SG-Sales-Users` group provides access to a business application. The business owner must periodically confirm that members still need access.

## Review questions

1. Does each user still need the access?
2. Is the access aligned with the user's role?
3. Should any access be removed?
4. Is the review result documented?

## Evidence checklist

- [ ] Review scope defined
- [ ] Reviewer defined
- [ ] Review performed
- [ ] Unnecessary access removed or retained with justification
- [ ] Outcome documented
