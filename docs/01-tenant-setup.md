# 01 — Tenant Setup

## Goal
Create an isolated Microsoft Entra environment for IAM practice.

## Prerequisites

- Microsoft account / Azure subscription or eligible developer environment
- Microsoft Entra admin center access
- Browser

## Lab naming convention

Tenant display name: `Contoso Labs IAM`
User pattern: `firstname.lastname@<lab-domain>`
Security groups: `SG-<BusinessUnit>-<Access>`

## Steps

1. Create or identify a dedicated test tenant.
2. Confirm the tenant name and domain.
3. Create test users for Sales, Finance, and IT.
4. Create security groups for each business role.
5. Record the tenant architecture in the README.
6. Take screenshots without exposing credentials or secrets.

## Evidence checklist

- [ ] Tenant overview
- [ ] Test users created
- [ ] Security groups created
- [ ] Naming convention documented

## Notes

Use fictional identities only. Never use company production identities or confidential enterprise data.
